# Python Programming Labs 

This repository contains my Python programming lab exercises and mini-projects completed as a first-year BSc (Hons) Artificial Intelligence and Data Science student at Middlesex University Dubai.

## 📚 Weekly Learning

- **Week 1 – Python Fundamentals:** Variables, data types, user input, calculations, and output formatting.
- **Week 2 – Control Flow:** Conditional statements, Boolean logic, loops, and loop control.
- **Week 3 – Functions:** Parameters, return values, default arguments, `*args`, `**kwargs`, scope, and modules.
- **Week 4 – Data Structures and File Handling:** Lists, tuples, dictionaries, sets, file operations, and exception handling.
- **Week 5 – Object-Oriented Programming:** Classes, objects, constructors, attributes, methods, and working with lists of objects.

## 💻 Mini-Project

**Record Check**

A Python mini-project developed progressively throughout the weekly labs. It applies concepts learned during the course, including calculations, conditional logic, functions, data structures, file handling, and object-oriented programming.
